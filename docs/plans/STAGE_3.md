# Этап 3: капсулы, вылупление, монеты, сохранения

**Цель:** замкнуть цикл. Доставленное яйцо вылупляется в пришельца, пришелец в капсуле приносит монеты, монеты сохраняются, лишних пришельцев скрещивают или продают. Тренажёра и улучшений ещё нет (этап 4): ⚡ по-прежнему меняется командой разработчика, но уже сохраняется в профиле.

**Главная проверка этапа:** понятно ли, зачем нести яйцо, и приятно ли вылупление.

## Модель

- **Капсула — место для пришельца.** Пришелец в капсуле приносит монеты каждую секунду. Новичку — 3 капсулы, остальные покупаются за монеты.
- **Яйца вылупляются всегда.** Доставил — яйцо легло в **инкубатор** отсека и тикает таймер (1 / 3 / 8 мин по редкости, по серверному времени, идёт и офлайн). Ограничения на число яиц в инкубаторе нет.
- **Грейд.** Яйцо стража k вылупляется только в пришельца из его набора: 5 ступеней (Обычный … Легендарный), доход внутри набора ×1 / ×2 / ×5 / ×15 / ×50. Набор стража k доходнее набора k−1 в 1,8 раза. Редкость и размер яйца сдвигают шансы к верхним ступеням («удача»), но не гарантируют их.
- **Вылупился** → встаёт в свободную капсулу. Нет свободной — выпадает **на пол отсека** с табличкой «имя + доход» и ждёт хозяина; поднятый уходит в **инвентарь** (10 мест). Инвентарь полный — лежит дальше, в профиле не теряется.
- **Окно отсека:** капсулы, инвентарь, кнопка «Лучших — в капсулы» (по доходу; остальные в инвентарь, лишние на пол), скрестить 3 → 1, продать.
- **Скрещивание:** 3 пришельца одного грейда → 1 случайный того же грейда, не ниже худшего из трёх, шансы сдвинуты вверх.
- **Офлайн:** доход капсул за время отсутствия с потолком 4 часа, экран «С возвращением!».

## Шаги

1. **Конфиги и домен с тестами:** `AlienConfig` (ступени, грейды, доход), `BayConfig` (капсулы, инвентарь, цены, офлайн); `Hatch` (шансы по удаче), `Crossbreed`, `Bay` (капсулы, инвентарь, пол, инкубатор, авторасстановка), `Offline`; профиль v2 (⚡, монеты, капсулы, инвентарь, пол, инкубатор, метка времени) с миграцией v1 → v2.
2. **Калькулятор баланса** (`lune run balance`): время до каждого стража для трёх профилей игроков, по конфигам. Крутим цифры до того, как они попадут в игру.
3. **Отсеки на станции:** `BayService` — отсек на игрока, модели капсул и инкубатора кодом; ⚡ из профиля (`SpeedService` читает `DataService`).
4. **Доставка → инкубатор → вылупление → доход:** `CarryService` отдаёт яйцо отсеку; вылупление по таймеру через планировщик; доход 1 раз в секунду; пол отсека.
5. **Сеть и HUD:** снимок данных при входе и дельты (тонкий слой на Zap); монеты в HUD; команды «поднять», «расставить лучших», «скрестить», «продать», «купить капсулу», «забрать офлайн-доход».
6. **Окно отсека** (Vide): капсулы, инкубатор с таймерами, инвентарь, скрещивание, продажа; экран «С возвращением!».
7. **Тексты** через скилл `game-copy`.
8. **Плейтест с тобой.**

## Технические решения

- **Профиль — источник истины отсека.** Модели капсул и пришельцев — отображение данных; не загрузилась модель — запись в профиле остаётся.
- **Домен не знает конфигов:** шансы, удача, доход и лимиты передаются параметрами, поэтому `Hatch`, `Crossbreed`, `Bay`, `Offline` тестируются в Lune. `PlayerData.template`/`load` получают стартовые значения (`Defaults`) от сервиса.
- **Адресация пришельцев — по `uid`** (счётчик в профиле), а не по индексу: индексы сдвигаются, а позже появятся мутации, из-за которых два пришельца одного вида перестанут быть одинаковыми.
- **Таймеры вылупления — unix-время сервера** (`os.time()`), хранятся в профиле; домен получает `now` параметром.
- **Доход — один тик в секунду** через общий планировщик, прибавка одним `DataService.update`.
