# Сообщество игры

**Status:** approved (2026-11-10)
Макета нет: окно собрано из готовых частей (`NeonWindow` компактного размера, золотая кнопка, плитка меню, тост).

## Зачем

Приглашение вступить в Roblox-сообщество игры «Fly & Steal Space Eggs» и разовый подарок за вступление (решение 098): **+10 000 к натренированной скорости**, игрок видит её с множителем своего джетпака (со стартовым — +10K ⚡, с ×32 — +320K ⚡). Экран отвечает на вопросы **что я получу** и **как это сделать** — одной кнопкой.

Правила Roblox: награда только за вступление в сообщество; ничего за лайк и «в избранное»; ссылок на Discord и соцсети в игре нет.

## Что на экране

**Плитка меню «Сообщество»** — шестая, последняя в ряду (после подарка), значок «сообщество» (новая иконка: две фигурки, как у остальных плиток), бейдж «1». Клавиша на ПК — **K**.

**Окно** (компактный `NeonWindow`, как подтверждения):
- шапка — «Сообщество игры», монеты, крестик (общая шапка);
- крупно по центру — значок ⚡ и сумма «+10K» (столько, сколько даст сейчас, с джетпаком игрока);
- строка — «Вступи в сообщество игры — и получи подарок один раз»;
- внизу одна золотая кнопка «Вступить».

**Тост** со значком ⚡: «Подарок сообщества: +10K ⚡».

## Раскладка

- **Телефон, 844 × 390:** плитка в ряду плиток 46 × 46 под целью роста; окно по центру, около 360 × 220 точек.
- **Планшет и ПК:** так же, `UIScale` увеличивает; на плитке в уголке — клавиша K.

## Состояния

| Состояние | Что видно |
|---|---|
| Туториал не пройден | плитки нет, окна нет, сервер подарок не даёт (решение 098: после туториала) |
| Туториал только что пройден, не в сообществе | после прощальной строки туториала — тост «Вступи в сообщество игры — получи +10K ⚡», появляется плитка с бейджем |
| Не в сообществе, подарок не получен | плитка с бейджем «1» |
| Уже в сообществе при входе (или вступил, пока не был в игре) | сервер сам выдаёт подарок, тост подарка; плитки нет |
| Нажал «Вступить» | окно Roblox «вступить в сообщество» поверх игры |
| Вступил в окне Roblox | кнопка показывает «Проверяю…» (неактивна), сервер проверяет членство; подтвердил — тост подарка, окно закрывается, плитка уходит |
| Закрыл окно Roblox, не вступив | окно как было |
| Сервер не нашёл в сообществе (Roblox не успел) | тост-отказ «Не видим тебя в сообществе — попробуй ещё раз через минуту», кнопка снова «Вступить» |
| Подарок получен | плитки нет; повторный вход, выход из сообщества и новое вступление ничего не дают |
| **Пустое** | не бывает |
| **Загрузка** | профиль не пришёл — плитки нет |
| **Ошибка** | Roblox не ответил на проверку — сервер повторяет; не вышло — тот же тост «попробуй ещё раз» |
| **Закрыто** | игра без сообщества в конфиге (`CommunityConfig`, по `game.GameId`) — плитки нет |

## Поведение

- «Вступить» — встроенное окно Roblox `GroupService:PromptJoinAsync` (на клиенте). Клиент сообщает серверу, что показал окно (аналитика), а после «вступил» или «уже в сообществе» — просит проверить. Подарок даёт только сервер, сам проверив членство (`GroupService:GetGroupsAsync`, с повтором), с лимитом частоты.
- Проверка при входе — тоже на сервере, без участия клиента.
- Закрыть окно — крестиком, тапом по затемнению, плиткой или клавишей K.
- Само окно не открывается: о подарке говорит тост после туториала и бейдж.

## Тексты

Новые (через `game-copy`): название окна, строка про подарок, кнопка «Вступить», «Проверяю…», тост-приглашение после туториала, тост подарка, тост-отказ. Термин «сообщество» / «community» — в глоссарий.

2. Показывать после туториала (пользователь, 2026-11-10).
