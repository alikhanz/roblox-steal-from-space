# С возвращением!

**Status:** approved (2026-11-07)
Макет: [../mockups/store-and-welcome.html](../mockups/store-and-welcome.html) — кадр «С возвращением!».

## Зачем

Игрок вернулся после отсутствия: пришельцы принесли монеты, тренажёр накачал ⚡ (с потолками офлайн-дохода, решение 062), яйца в инкубаторе дозрели. Экран — маленький праздник при входе: **сколько ты получил, пока тебя не было**. Тут же можно взять ещё раз столько же за робуксы («Забрать ×2», решение 064).

Старый экран — серая плашка 360 точек шириной: заголовок, два числа, предложение и две старые кнопки.

## Что на экране

Компактное окно в стиле `NeonWindow` (примерно 470 × 240 точек), по центру, поверх всего:
- **шапка:** «С возвращением!» и крестик (без монет — их видно в HUD за окном);
- «Тебя не было 7 ч 12 мин»;
- **две крупные плитки:** монеты «[монета] +1.2M» с подписью «принесли пришельцы» и ⚡ «[молния] +34K» с подписью «накачал тренажёр»; плитка в цвете своего ресурса;
- «[яйцо] Готово яиц: 3. Вылупи их на острове» — только если есть готовые;
- **низ:** большая зелёная «Забрать» и кнопка цвета робуксов «×2 за [R$] 5».

## Раскладка

- **Телефон, 844 × 390:** окно ~56 % ширины экрана; две плитки рядом.
- **Планшет и ПК:** так же, `UIScale` увеличивает.
- Поверх HUD и окон; подарок за вход ждёт, пока это окно не закроют (как сейчас: `welcomeOpen`).

## Состояния

| Состояние | Что видно |
|---|---|
| Обычное | время, две плитки, «Забрать» и «×2 за …» |
| Яиц нет | строки про яйца нет |
| ⚡ не прибавилось (тренажёр не куплен — бывает ли?) | плитка ⚡ всё равно видна с «+0» (решится в коде: можно скрыть) |
| Цена ×2 не пришла | «×2 за …», кнопка не нажимается |
| ×2 куплен | плитки показывают удвоенные числа, кнопки «×2» больше нет, тост «Ещё ●+… и ⚡+…» (как сейчас) |
| Нет магазина (непубликованный плейс) | только «Забрать» |
| **Пустое** | не бывает: экран приходит, только когда есть награда |
| **Загрузка** | нет: экран открывается, когда сервер прислал награду |
| **Ошибка** | покупку отменили в окне Roblox — окно как было |
| **Закрыто** | новичок без пришельцев на местах и тренажёра — награды нет, экран не приходит |

## Поведение

- Награда уже на счету: «Забрать», крестик и тап по затемнению просто закрывают экран.
- «×2» — окно покупки Roblox (`CollectDouble` ступени награды); выдаёт сервер по чеку.
- После закрытия может открыться подарок за вход (как сейчас).

## Тексты

Уже есть: `welcome.back.title`, `welcome.eggsReady.hint`, `welcome.claim.button`, `welcome.double.button` («×2 за {price}», цена — со значком робукса).
