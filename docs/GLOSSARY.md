# Глоссарий

Каждый игровой термин везде называется одинаково. Новый термин сначала добавляется сюда. **ID** — для кода и конфигов, не меняется никогда.

## Мир

| ID | Русский | English | Заметки |
|---|---|---|---|
| `Station` | станция | station | Хаб, безопасная зона |
| `Bay` | отсек | bay | Личная база игрока на станции |
| `Airlock` | шлюз | airlock | Вход в купол |
| `Dome` | купол | dome | Силовое поле станции; стражи не проходят |
| `StationBorder` | граница станции | station border | Сфера со светящимся кольцом вокруг купола; за ней стражи не гонятся |
| `Space` | космос | space | Всё вне купола |
| `Nest` | гнездо | nest | Место, где лежит яйцо |
| `BlackHole` | чёрная дыра | black hole | Край карты, затягивает |
