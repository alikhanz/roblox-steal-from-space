# Глоссарий

Каждый игровой термин везде называется одинаково. Новый термин сначала добавляется сюда. **ID** — для кода и конфигов, не меняется никогда.

## Мир

| ID | Русский | English | Заметки |
|---|---|---|---|
| `Station` | станция | station | Хаб, безопасная зона |
| `Bay` | отсек / остров | bay / island | Личная база игрока: свой остров под куполом вокруг центральной станции (решение 068). «Остров» — о месте в мире, «отсек» — об окне и его содержимом |
| `Airlock` | шлюз | airlock | Вход в купол |
| `Dome` | купол | dome | Силовое поле станции; стражи не проходят |
| `StationBorder` | граница станции | station border | Сфера со светящимся кольцом вокруг купола; за ней стражи не гонятся |
| `Space` | космос | space | Всё вне купола |
| `Nest` | гнездо | nest | Место, где лежит яйцо |
| `BlackHole` | чёрная дыра | black hole | Край карты, затягивает |

## Добыча и существа

| ID | Русский | English | Заметки |
|---|---|---|---|
| `Egg` | яйцо | egg | Полное: «космо-яйцо» / space egg. Не «икра», не «кладка» |
| `Place` | место | spot | Где стоит пришелец на площадке острова и приносит доход («Мест: 12/30»); было «капсула» (решение 068) |
| `EggPod` | капсула | pod | Капсула инкубатора, в которой греется яйцо (решение 068). Она же — место в инкубаторе: «+1 капсула», «Все капсулы заняты» |
| `Hatch` | вылупление / вылупить | hatch | |
| `Alien` | пришелец | alien | То, что вылупляется |
| `AlienKind` | вид | kind | Один из видов пришельцев стража (решения 075, 080): основной (детёныш стража, его имя), второй, редкий, позже — новые; доход у видов одного стража одинаковый. Названия — в разделе «Виды пришельцев» |
| `Incubator` | инкубатор | incubator | Где лежат доставленные яйца, пока не вылупятся |
| `ReadyEgg` | готовое яйцо / «Готово!» | ready egg / "Ready!" | Яйцо в капсуле, у которого вышло время: держит капсулу, пока игрок его не вылупит (решение 059) |
| `IncubatorSlot` | капсула (инкубатора) | pod | Одно яйцо в капсуле, все греются одновременно; новичку 2, докупаются до 12. Было «место в инкубаторе»: «место» теперь только у пришельцев (решение 068) |
| `EggQueue` | очередь / ждёт капсулы | queue / waiting for a pod | Яйца у инкубатора, когда свободных капсул нет: не греются, переходят в инкубатор по порядку доставки |
| `Shelf` | стеллаж | shelf | Стеллаж с нишами на острове — единственный запас пришельцев не на местах (решение 110; инвентаря больше нет): 24 ниши, «Стеллаж 12/24». Полный стеллаж и нет свободного места — яйца не вылупляются («Стеллаж полный»). Было «пол» |
| `Income` | доход | income | Монеты в секунду от пришельца на месте |
| `Tier` | ступень | tier | Место пришельца внутри грейда; названия — как у редкостей |
| `Mutation` | мутация | mutation | |
| `Rarity` | редкость | rarity | |
| `Luck` | удача | luck | Есть только у звёздного яйца: оно вылупляется по шансам большого яйца (решение 113) |
